# Privacy policy

_Last updated: 2026-10-27_

PDF Unseal does not collect, store or share any personal data.

- **Your files stay on your computer.** PDF Unseal reads the PDF you choose and writes the unlocked copy to the location you choose. Files are never uploaded or sent anywhere.
- **Passwords are not stored.** The password you enter is used only to open that PDF and is discarded when the app is done with it.
- **No network access.** PDF Unseal does not connect to the internet.
- **No tracking.** PDF Unseal contains no analytics, telemetry, advertising or crash reporting.

If you install PDF Unseal from the Microsoft Store, Microsoft may collect data about the installation under its own privacy policy, which PDF Unseal does not control.

Questions about this policy: open an issue at https://github.com/Monska85/PDF-Unseal/issues.

# Informativa sulla privacy

_Ultimo aggiornamento: 27/10/2026_

PDF Unseal non raccoglie, conserva né condivide alcun dato personale.

- **I tuoi file restano sul tuo computer.** PDF Unseal legge il PDF che scegli e scrive la copia sbloccata nella posizione che scegli. I file non vengono mai caricati né inviati altrove.
- **Le password non vengono conservate.** La password che inserisci serve solo ad aprire quel PDF e viene scartata quando l'app ha finito di usarla.
- **Nessun accesso alla rete.** PDF Unseal non si connette a internet.
- **Nessun tracciamento.** PDF Unseal non contiene analisi statistiche, telemetria, pubblicità né segnalazione automatica degli errori.

Se installi PDF Unseal dal Microsoft Store, Microsoft potrebbe raccogliere dati sull'installazione secondo la propria informativa sulla privacy, che PDF Unseal non controlla.

Domande su questa informativa: apri una segnalazione su https://github.com/Monska85/PDF-Unseal/issues.
